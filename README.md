# India Equity Board

A fundamental board of Indian equity: Darwin/Nalanda-style stock screening (General
Portfolio) plus a real India/US/China + commodity macro dashboard (Macro Intel),
built from live data.

This is a static export of a personal research tool. Personal holdings, portfolio
value, trades, and thesis notes are never published here — only the general
screening/watchlist analysis and macro indicators are included. See the source
project's `export_public_data.py` and `build_static_site.py` for exactly what is
and isn't included.

Published via GitHub Pages: https://manishkakran.github.io/india-equity-board/
